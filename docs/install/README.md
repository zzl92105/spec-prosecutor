# Installation

Recommended: install the portable skill into a project. See the [main README](../../README.md#项目级安装).

- [Codex](codex-local.md)
- [Claude Code](claude-code.md)
- [GitHub/local source](github-direct.md)
- [Optional Homebrew distribution](homebrew.md)
- [Legacy Cursor integration](cursor.md)

Codex and Claude Code default to enabled (`on`) with native explicit invocation and natural-language PRD review requests. `启动sp` is an optional alias; `off` exports refuse reviews. Cursor retains its legacy phrase-gated behavior.
